# 完整提示詞範本

將以下欄位全部填成實際內容；不要將佔位符交給用戶。

```text
頁次：〔第幾頁／共幾頁（一段文本可拆成多頁）；本頁唯一訊息（一句話）；估計講授時間；文字量預算；與前後頁的銜接〕。
用途：科學／教學示意圖，供〔受眾〕理解〔核心問題〕。
模式：〔全新生成／編輯指定圖片〕。
來源：〔URL、頁次、標題；供追溯，完整事實在下方，不要求生圖端讀網址〕。
圖片角色：〔精確檔名及角色；無則省略〕。
保留：〔編輯時必須保持的風格、物件或內容〕。
替換：〔必須移除並取代的舊內容〕。
核心結論：〔一句話〕。
規格：〔尺寸比例〕，〔語言〕，〔視覺風格〕，清晰的大字與充分留白。
版面：〔區塊位置、閱讀順序、每區角色〕。
逐區內容：
1. 〔區塊名稱；完整標題和文案；每種物件確切數量、形狀、顏色；公式；連接關係〕。
2. 〔同上〕。
圖例：〔顏色／形狀／線條所代表意義〕。
數學排版：〔所有符號與公式一律以 LaTeX 寫出（變數、上下標、希臘字母、運算子、含符號的等式與數值代入，包括標題、圖例、軸標與標籤裡的符號），並附符號定義與近似記號；要求正確渲染上下標，不把 LaTeX 指令原樣印出；不用 Unicode 上下標或拼寫（σ² → $\sigma^2$）〕。
限制條件：〔類別數、資料設定、實驗範圍、概念示意標示〕。
底部重點：〔完整文字〕。
避免：〔錯誤數值、混用資料角色、不支持的結論、錯誤箭頭；文字截切、重疊、雜亂裝飾〕。
檢查：〔這張圖最重要的計數、條件與公式核對項目〕。
原生元件：〔僅在之後要轉成 JianBauDau 原生頁時填：每區使用的元件(矩形／橢圓／三角形／菱形／五邊形／星形／箭頭／多邊形／折線／連接線)、漸層、透明度、陰影、虛線；無法原生重現的部分改成何種幾何簡化圖示〕。
```

文字很多時，先減少重複說明並放大關鍵字；必要時拆成多張，每張提示詞仍自足。跨圖共用相同符號與圖例。

提示詞模式的附加交付格式：
- 來源範圍與讀取限制。
- 完整提示詞（單一可複製區塊，或每張一區塊）。
- 必須一起提供的附件及角色。
- 尚待生成後核對的 3–5 個具體項目；不得標記已通過。

原生簡報目標的附加要求：
- 逐區列出元件種類與位置，曲線與函數圖註明「由折線描出」，並附關鍵座標點或公式。
- 文字另放獨立文字框，形狀內不放長文字；中英文各自獨立。
- 數學符號與公式一律以 LaTeX `$...$` 寫入各區文字，同一區內符號、等號與數值放在同一個 `$...$`。
- 不使用照片、手繪質感與複雜光影。
