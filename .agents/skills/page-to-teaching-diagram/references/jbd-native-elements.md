# JianBauDau 原生繪圖元件速查(圖解要轉成原生簡報時使用)

示意圖之後若要做成 JianBauDau 原生簡報頁(可編輯、可翻譯,不是嵌入圖片),設計與提示詞就要用原生能重現的元件來描述。本文件是本技能自帶的速查,不需要另外開別的檔案。格式權威仍是 JianBauDau 的檔案格式規格;本表依該規格整理,有疑義以規格為準。

## 頁面基本

- 一頁 1280×720(16:9)。一個節點只有 `text` 或 `shape`;原生頁不使用圖片、影片、嵌入節點。
- 文字支援 Markdown;公式用 KaTeX `$...$`(行內)。公式裡避免 `\dfrac`、`\iff`、cases 環境,以及 `\text` 內的中文。
- 非矩形形狀(橢圓、三角、菱形、五邊形、星形、箭頭、多邊形)不放長文字:圖形當圖示,文字另放一個獨立文字框。

## 形狀

| 要畫的東西 | 原生元件 |
|---|---|
| 卡片、色塊、背景、長條 | 矩形(可設圓角) |
| 圓、點、節點、液體 | 橢圓 |
| 警示、三角指標 | 三角形 |
| 判斷、決策、分子 | 菱形 |
| 五邊形、徽章 | 五邊形 |
| 重點、能量、評分 | 星形 |
| 方向、流向 | 箭頭(形狀) |
| 任意輪廓(山形、漏斗、梯形、陰影區、曲線圍出的區域) | 多邊形:3~200 個頂點,自動封閉,可用曲線點 |
| 曲線、折線、函數圖、軸線、開放路徑 | 折線:2~200 個點,只描邊、不封閉,可平滑、可虛線 |
| 兩物件之間的關聯線 | 連接線:同頁兩節點之間,16 個掛點,箭頭小/中/大,可加標籤;標籤底是近白色,文字用深色 |

## 填色與效果

- 填色透明度:做半透明遮罩、毛玻璃、重疊區域。
- 漸層:線性(可指定角度)、徑向(中心到邊緣)、多色(最多 8 個中間色)。
- 陰影:顏色、透明度、模糊、位移;沿輪廓走,對各形狀與文字都有效。深色底上用亮色光暈才看得到。
- 邊框:實線、虛線、點線、雙線;線寬、圓角可調。
- 線與箭頭:折線可加箭頭;虛線用來表示「示意」「對應」「未發生」。

## 設計圖解時的取捨

1. 優先用上表元件組合,就能被原生還原;要寫成提示詞時,逐區寫出用哪種元件、位置、顏色與數量。
2. 精確科學曲線與數據圖:仍用程式算好座標,再以折線描出;不要要求生圖模型憑空畫。
3. 照片、插畫、手繪質感、複雜光影:原生無法重現。要原生版就改成幾何簡化圖示,並在提示詞註明「簡化為幾何圖示」。
4. 文字密度:原生頁中文字一般不小於 12 px(投影時 14 以上較佳);一個文字框一個意思,不靠一個大框塞多段。
5. 色彩對比:文字壓在漸層或半透明上,每個顏色都要和文字達標;連接線標籤字色用深色。
6. 雙語頁:中英文各自獨立文字框,不要混成一個框。

## 靈活組合的例子

- 偏差與變異:折線畫真實函數與擬合曲線,多邊形半透明填出誤差帶,虛線標平均預測,箭頭標偏差大小。
- 門檻或收縮:折線畫分段函數,星形標最佳點,漸層底色區分「歸零區」與「保留區」。
- 流程與管線:矩形卡片加連接線(標籤寫轉換),陰影突出當前步驟,虛線框起可省略的步驟。
- 層級關係:徑向漸層表中心到外圍的影響力,同心橢圓加透明度。
