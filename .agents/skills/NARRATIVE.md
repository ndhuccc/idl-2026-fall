# NARRATIVE.md — 敘事、脈絡與備課(講義與投影片共用)

`textbook-lecture-notes`(講義)與 `view-from-text`(投影片)都先讀這份。
**你的角色是這個領域的專家教授**:把來源資料「消化」之後,用自己的話,由淺而深、由因至果地重新講一遍。
不是搬運、轉錄、按來源頁序逐頁改寫,也不是把來源的每一句話各做成一頁。

這份文件回答三個問題:怎麼消化來源(§1)、單元內怎麼排順序(§2)、頁與頁之間怎麼銜接(§3)。§4 是禁止的做法,§5 是自我檢查。

## 0. 先做知識地圖,再全新撰寫(硬規則)

**順序固定**:消化來源 → 知識地圖(老師確認)→ 全新撰寫講義 → 全新撰寫投影片。講義與投影片都從**知識地圖**出發,不是從來源逐句改寫,也不是把講義逐頁搬成投影片。

**講義先行(硬規則,老師 2026-10-26 確認)**:
1. 製作順序是 **講義 → 稽核 → 講義冷讀 → 簡報**。簡報由**已通過的講義**抽出重點與圖,不得反過來由簡報卡片拼成講義。
2. **講義是主體**:小節對應「想法」(一個因果步驟),不是簡報的「頁」;承載完整說明、逐步推導、符號表、先備補課框、逐題解答。簡報只取主線與圖,放不下的留在講義。
3. **進入簡報前的關卡**:`audit_lecture.py` 對該講義 FAIL 為 0,L12–L22 的警告逐項處理或寫明理由;講義冷讀(見下)通過;老師確認。未通過不得開始做簡報。
4. **篇幅關係**:講義教學正文應明顯多於簡報文字;`audit_lecture.py` L17 量測講義句子與簡報重疊,超過 20% 表示講義只是簡報腳本。簡報可引用講義的關鍵句,但不是主要來源。
5. 簡報完成後若更動內容,**先改講義**,再同步簡報;雙方的符號、參數、正負號、數字必須一致。

**知識地圖有兩層**,寫進盤點報告(格式固定,見 `INVENTORY_FORMAT.md`):

1. **章級地圖**:本章所有 KP 的清單,標出每個 KP 的一句話主張、它依賴哪些前面的 KP、它留下什麼問題給後面的 KP,據此決定**教學順序**(來源順序若不合因果就重排)與各 KP 的角色(地基、核心、延伸、應用)。
2. **KP 級地圖**:每個 KP 的備課筆記(§1 備課五步),以及依「**學生程度**」(`LEVELS.md` §1–§2)與「**簡報時長**」(`LEVELS.md` §7)決定的**講法與頁數**:
   - 程度決定:講到多深、用什麼術語、放不放推導。
   - 時長決定:主線的細度與內容量(**頁數不設上限**,老師 2026-10-25 指示);放不下的細節放進講義。
   - 在地圖上寫出這個 KP 的頁序與銜接表(§3),頁數必須在預算內。

**全新撰寫的意思**:
- 說明文字、順序、版面、圖的構圖都由你依知識地圖重新設計與撰寫;**不得逐句複製或只改幾個字**來源的句子(`audit_deck.py --source` 與 `audit_lecture.py` 的原創性檢查會比對)。
- 來源的**事實、定理、數字與數值例**不改(`view-from-text` §3);來源的比喻、口訣、習題與附圖可以沿用,但要放在它在因果鏈上的位置,並標明出處。
- 來源有錯,用正確值並列給老師,不要照抄。

## 0.1 講義的先備與補課(硬規則)

每個 KP 的盤點表列出 **3–5 個必要先備**(概念與符號),各給一個 1–2 題的快速自測;讀者可能不熟的先備,在講義開頭放一個**補課小框**(用白話講一遍,附一個小例子),或連到前面的 KP。`LEVELS.md` 的程度只表示預設的先備,不保證讀者記得;**符號表**(符號、意義、維度、首次定義位置、本例設定)與參數(例如 a=1、學習率)必須在第一個算例之前給出。

## 1. 先消化,再設計:備課五步(寫進盤點表,等老師確認)

動手設計任何一頁之前,對**每個知識單元**(KP)完成下面五件事,結果寫成「備課筆記」放進盤點表:

1. **核心問題與一句話結論**:這個單元要回答什麼問題?結論是什麼?(一句話,能獨立成立。)
2. **概念依賴圖**:列出本單元用到的所有概念與符號,標出「要懂 A,必須先懂 B」,據此排出**由淺入深**的學習順序。來源順序若不符合這個順序,**以教學順序為準**並說明為什麼重排。
3. **因果鏈**:用「因為…所以…」把整個單元串成一段話(5 句以內)。串不起來,代表你還沒消化,不可以開始做頁面。
4. **為什麼需要**:每個新概念,先回答「沒有它會怎樣?」,再講它是什麼。
5. **主例子與反例**:選**一個主例子(running example)**貫穿單元(同一個函數、同一組數字、同一張圖),讓學習者看到概念一步步長在同一個例子上;再選一到兩個反例或易錯點放在最後。不要每頁換一個新例子。

> **來源本身就是投影片或條列式網頁時**:來源的頁序只是參考。先把來源的內容攤平成概念清單,再依第 2 步重排,**不得一張來源投影片對一頁新投影片(或講義一小節)**。來源的比喻、口訣、數值例、練習照樣保留(`SKILL.md` §3),但放在它在因果鏈上的位置。

## 2. 單元內的敘事弧(固定骨架,頁型依 `VISUAL_AND_LAYOUT_GUIDE.md` §3 選)

每個單元依這條弧排順序,缺哪一環就在盤點表寫出理由:

| 環節 | 回答的問題 | 與前一環的關係 |
|---|---|---|
| ① 動機 | 為什麼要學這個?遇到什麼問題? | 承接上一單元留下的問題 |
| ② 直覺 | 用一個圖或比喻看懂它在做什麼 | 對①的問題給出直覺的答案 |
| ③ 定義 | 正式說法與符號 | 把②的直覺寫成精確的式子 |
| ④ 機制 | 它怎麼運作、為什麼成立 | 由③推出 |
| ⑤ 算例 | 用主例子逐步算一遍 | 驗證④ |
| ⑥ 條件與限制 | 什麼時候成立、什麼時候失效、常見迷思 | 對⑤的結果提出「但是」 |
| ⑦ 練習 | 自己做一次 | 檢驗①–⑥ |
| ⑧ 小結與下一步 | 這個單元留下什麼問題給下一單元 | 開啟下一單元的①動機 |

頁與頁的關係只能是下列幾種(銜接語要寫明是哪一種):
**因果**(所以)、**舉例**(例如)、**深化**(更進一步)、**對比**(相對的)、**反例**(但是)、**限制**(只在…成立)、**應用**(用在…)。

## 3. 頁與頁之間怎麼銜接(硬規則)

1. **每頁一個問題**(`VISUAL_AND_LAYOUT_GUIDE.md` §1.1),這個問題必須是**上一頁答案自然引出的下一個問題**。寫不出「這頁為什麼接在上一頁後面」,代表順序有問題。
2. **銜接條(bridge)**:每個內容頁(連續頁「(續)」除外)在副標下方放一個**銜接條**:一個文字節點,`name` 含 `bridge`,一到兩行,中文在前、英文斜體在後,說明**上一頁留下什麼,這一頁要回答什麼**。**必須具體**:提到上一頁的具體發現(主例子裡的東西或數字),並以一個真正的問句結尾(`view-from-text/CLARITY.md` C14;`audit_deck.py` R4、R5)。例如:
   `上一頁算出一步後損失從 16 降到 10.24 → 這一頁問:步長加大一倍會怎樣?`
   單元的第一頁,銜接條連到**上一個單元留下的問題**(全份簡報第一頁除外)。
3. **先定義,再使用**:任何符號、術語、縮寫,必須在第一次使用**之前**的頁面或同一頁已經定義(`SKILL.md` §3C);**術語包含看似日常的詞**(面、凸、階梯、編碼…),定義用白話、放在術語卡(`view-from-text/CLARITY.md` C12),標題與銜接條也不得先用。不可以前向引用「後面會講」來代替定義。
4. **一頁最多引入 1–2 個新概念**;新概念之間有依賴時,先出現被依賴的。
5. **沿用主例子**:同一單元的算例頁、圖、練習優先沿用主例子的函數與數字;換例子要有理由,並在銜接條說明為什麼換(例如「換成 η=1 看反例」)。
6. **單元之間**:全章第一頁前有一張「地圖頁」(各單元一句話與先後關係,用原生節點加 connector);每個單元最後一頁寫「留下的問題」,下一單元第一頁的銜接條接住它。
7. **標題串能讀**:把單元內所有頁的標題依序讀一遍,應該像一個**故事**:不看內文,也能知道每頁的主張、頁與頁怎麼接(標題是一句白話完整主張,`view-from-text/CLARITY.md` C13)。這一條由冷讀者檢查(C17)驗證,不是自己讀一遍就算。
8. **講者備註要寫承上啟下**:每頁備註至少有一句「上一頁…」與一句「接下來…」,以及這頁專屬的內容(引用本頁的一個數字、符號或概念),**不得是通用套話**。

## 4. 禁止的做法

- 一句話一頁、一個比喻一頁、一個來源投影片一頁。
- 照來源頁序搬運,卻說不出因果。
- 用「視覺休息頁」「重複符號表」「通用提醒頁」湊規則或湊頁數。
- 空頁:只有標題與頁尾,沒有正文、圖或連線。
- 重複的頁:同一標題或同一正文出現三次以上。
- 逐句複製或近似改寫來源的句子;為了湊內容而多開頁(為清晰而增頁不在此限)。
- 為了通過稽核工具而加內容。稽核通過只是最低要求,不代表講得好。

## 6. 故事書標準(2026-10-24 老師指示)

老師的期望:**讀這份簡報,像讀一本劇情緊湊、環環相扣、行雲流水的故事書;既有親和力,又讓人豁然開朗。** 不是把講義切成頁。

**備課時多做三件事**(寫進盤點表,`INVENTORY_FORMAT.md` 第 3、4 部分):
1. **故事大綱**(一段話)：主角是誰（主例子裡的點、數字或問題）、他想做什麼、卡在哪、怎麼突破、突破後世界變成怎樣。
2. **開悟時刻**:學生讀到哪一頁會說「原來如此」？那一頁用什麼畫面或算例達成。
3. **術語表**:每個術語的白話說法與主例子裡的對應物（`view-from-text/CLARITY.md` C12）。

**頁序表要能「一句一句接下來」**:`頁 | 白話主張(標題) | 上一頁留下的疑問 | 這頁怎麼回答 | 這頁留下的疑問`。把「這頁留下的疑問」和下一列的「上一頁留下的疑問」連著讀，必須是同一句話；對不起來就是斷裂。

**三種頁的節奏**(交替出現，避免連續多頁都在下定義):
- **疑問頁**:把難題擺上檯面，讓人想知道答案(圖、反例、一個算不通的數字)。
- **揭曉頁**:給出答案，含白話、式子、算例。
- **回味頁**:退一步用比喻或對照整理，說清楚「這跟前面學的有什麼關係」，並拋出下一個疑問。

**語氣範例**(同一件事的兩種寫法):

| 官樣 | 故事書 |
|---|---|
| 要分清楚半空間交集與多個編碼的聯集。 | 一塊區域像一個沒有凹洞的盤子。把兩個盤子擺在一起，整體就可能出現凹洞，甚至分成兩半。 |
| 本頁定義判別分數，允許偏置 w0。 | 我們給每個點打一個分數：分數為正，猜 A；否則猜 B。式子裡多出來的 w0 就是一個「起跑線」，讓直線不必經過原點。 |
| 已證明：這組實際碼沒有單一超平面能全對。 | 試了所有的線，一條都不行。為什麼？看下面四個點，A 和 B 交錯排，這就是 XOR。 |

**禁止**:在簡報裡寫「本頁…」「本單元…」之類談論投影片本身的句子；用同一個備註套句；把講義的條列逐條搬成頁面（`CLARITY.md` C16）。
