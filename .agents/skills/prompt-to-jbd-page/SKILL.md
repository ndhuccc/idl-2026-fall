# prompt-to-jbd-page:提示詞 → 直接設計 JianBauDau 原生頁

目標:把一段生圖提示詞(或頁面規格)當成**版面說明書**,直接用原生節點(shape / text / polygon / polyline / ellipse / KaTeX)設計出一頁可編輯的 JianBauDau 頁,**不經過生圖**。這樣文字與公式一開始就正確、計算過程可以畫成圖、數值可以由腳本驗證,通常也比「生圖 → 重畫」快。

## 選技能

| 輸入 | 用哪個 |
|---|---|
| 提示詞或頁面規格(文字) | **本技能** |
| 一張現成的圖片(截圖、資訊圖) | `image-to-jbd-page` |
| 使用者明確要求「先生圖,再轉成原生頁」 | 先生圖,再交給 `image-to-jbd-page` |

## 依賴:`image-to-jbd-page`(必須與本技能放在同一個技能目錄下)

本技能沒有自己的程式,工具全部用同層的 `image-to-jbd-page` 技能。以下 `<IMG>` 代表它的資料夾,依序尋找:

1. 環境變數 `JBD_PAGE_SKILL`(若有設定)
2. 本技能資料夾的同層 `../image-to-jbd-page/`
3. 都找不到 → **停止並回報**「缺少 image-to-jbd-page 技能」,不要自行憑空寫節點格式。

會用到:`<IMG>/tools/jbd_page.py`(建頁庫 `Page`)、`new_deck.py`、`insert_page.py`、`preview_deck.py`、`<IMG>/docs/AI_AGENT_FILE_FORMAT_SPEC.md`。動手前先讀 `<IMG>/SKILL.md`(建頁 API、已知陷阱、驗證規則)。用 `Page(src_w=1280, src_h=720)` 當虛擬畫布。`compare.py` 需要原圖,本技能沒有原圖,**不用它**,只看預覽圖。

## 與 image-to-jbd-page 規則的差異(以本技能為準)

- **補充內容**:`image-to-jbd-page` 規定「只重畫圖上有的內容,不補充」。提示詞模式可以加入講義有、提示詞沒寫的內容,以及講義沒有的**補充**,但補充一定要標示(見下)。
- **字級**:提示詞若有指定字級就照做;否則一般頁面 ≥ 13px。**放進課程 repo 的簡報時,以課程規則為準(原生節點字級 ≥ 16px)**。

## 流程(照順序)

1. **讀來源,核對事實。** 找講義的順序:提示詞給的連結 → **本地課程 repo 的講義**(例如 `lectures/lecNN-kpMM-*.md`,依課名、單元或 KP 編號、主題關鍵字找)→ 課程網站(需要網路時才用,受限環境可能被擋)。找到就抓該小節全文,逐條核對提示詞裡的公式、數字、措辭。
   - 數字或公式與講義不符 → 以講義為準,並在回報中說明改了什麼、為什麼。
   - 提示詞的說法與講義衝突(例如「以測試集為依據」但講義說直接用測試集挑模型是作弊)→ 改成講義的說法並回報。
   - 提示詞要的內容講義該小節沒有(名稱、處方、性質)→ 先在同一份講義其他段落找;找到就註明出處,真的沒有就加「補充」小標籤,或在不影響主旨時拿掉並回報。
   - **找不到講義**:以提示詞本身為唯一依據:公式與數字自行重算,並由建頁腳本 assert;此時不加「補充」標籤(沒有可對照的來源)。回報時明說「未與講義核對,只驗證了計算」。提示詞裡看起來有誤的概念或說法不要自行改寫,照原文製作並在回報中列出疑點,由使用者決定。
2. **規劃版面(不參考任何生成圖)。** 依提示詞的「版面」與「逐區內容」切區塊,寫一段版面說明:每區的位置、顏色、標題、文字、圖形。原則:
   - **把計算畫出來,不只寫出來**:例如數個數就點亮並編號、加總就用首尾相接的長條、長度就畫直角三角形、差距就畫兩點間的箭頭;圖形尺寸由實際數值算出。
   - 每張卡片的結構一致(標題 → 公式 → 計算圖 → 數值 → 一句意義 → 性質標籤),方便比較。
   - 配色、背景、字級依提示詞「規格」;頁面 16:9(1280×720)。
3. **寫建頁腳本。** 一個 `build_<name>.py`(`sys.path` 指向 `<IMG>/tools`):
   - 所有數值由程式計算(例如由向量算範數),並用 `assert` 檢查提示詞「檢查」欄列出的結果;數值錯就讓建頁失敗。
   - **所有數學符號與公式都用 KaTeX `$...$`**,包括卡片標題、圖例、軸標、長條標籤與重點橫幅裡的符號(`$\sigma^2=0.09$`,不寫 `σ² = 0.09`、`x₁`、`w*`、`≥`、`≈`);完整規則見 `page-to-teaching-diagram` 技能的「數學符號與公式」。長公式放獨立文字框,與中文可行內混排或分開;建好頁後掃描文字節點,`$...$` 之外不得有 Unicode 上下標、希臘字母、`√ ≈ ≥ ≠ ∈ → ∗` 或 `^`、`_`、`sqrt` 拼寫。
   - 公式全用 KaTeX `$...$`,與中文放在不同節點;開根號等符號只放在該放的公式。KaTeX 限制(不支援 `\dfrac`、`\iff`、`cases`;`\text{}` 內不放中文)見 `<IMG>/SKILL.md`「已知陷阱」。
   - 中英文不混在同一段落(括號內的簡短英文術語可以)。
   - 加入講義沒有的內容時,旁邊放「補充」小標籤。
   - `P.dump()` 的警告(字太小、溢出、超出頁面)全部處理。
4. **輸出。** `new_deck.py` 建新簡報(或 `insert_page.py --after N / --replace N` 加入現有簡報),再用 `preview_deck.py` 出預覽 PNG。
5. **看圖迭代至少兩輪。** 實際看預覽圖,修重疊、擁擠、對齊、留白、文字截斷;`overflowing boxes` 必須為 0;簡報需通過格式說明書的驗證規則;不得有 image 節點。
6. **回報。** 檔案路徑、節點數、預覽圖;數值核對結果(腳本 assert 的輸出);依講義修改的地方與標成「補充」的地方;自己補寫的措辭(標題、短標籤);提醒預覽只是近似,請在 JianBauDau 實際確認。

## 在課程 repo(pr-2026-fall 等)使用時

與 `image-to-jbd-page`「在本課程 repo 使用時」一節相同:
- 簡報在 `slides/lecNN-kpMM-*.jbd.json`(中文)與 `...-en.jbd.json`(英文),**兩份都要加頁**,英文版用英文文字(提示詞若只有中文,先確認英文內容或請使用者提供)。
- 加頁後 `python3 scripts/check_slides.py` 不得有 FAIL;`CHANGELOG.md` 記一行(類型「更新」,台北時間);照 `AGENTS.md`:**先取得教授同意**才提交,提交到 `main`、訊息用繁體中文;建頁腳本存到 `.agents/skills/view-from-text-v3/examples/`。
- 直接改 `.jbd.json` 會在原腳本重建時被覆蓋,要告知使用者。

## 不要做

- 不要先生圖再照圖重畫(除非使用者明確要求;那時改用 `image-to-jbd-page`)。
- 不要用 image 節點貼圖,也不要 `asset:` 或 base64。
- 不要擅自加入講義沒有的結論;補充一定要標示。
- 未經同意不要提交或推送到任何 repo。
