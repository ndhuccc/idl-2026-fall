# 頁面規格(內容層,風格無關)

每個 KP 一份 `圖解證據表.json`,是一個陣列,每頁一個物件。**兩種風格共用同一份內容規格**,風格只決定畫法。

| 欄位 | 必填 | 說明 |
|---|---|---|
| `page` | ✔ | 頁序,從 1 起 |
| `title` | ✔ | 標題,結論句 |
| `takeaway` | ✔ | 本頁必須帶走的一句話 |
| `source_anchors` | ✔ | 陣列,講義錨點(用 `check_coverage.py --list` 列出的字串),一頁可對多個;講義沒有的新增頁寫 `["(新增)"]` 並在 `note` 說明 |
| `bridge` | 第 2 頁起 ✔ | 承接上頁的一句話(也是頁面小標) |
| `new_terms` | 選填 | 本頁第一次出現的術語/符號與白話 |
| `visual` | ✔ | 主圖是什麼(圖型、元件、數量、顏色) |
| `math` | ✔ | 本頁出現的公式與算例(LaTeX),無則 `[]` |
| `numbers` | 有數字時 ✔ | 對應 `數值驗算.json` 的鍵 |
| `self_check` | 選填 | `true` 表示練習、檢核或常見迷思頁 |
| `mascot` | 導學版 ✔ | `{mood, prop, bubble}`;圖解版不填 |
| `note` | 選填 | 新增內容、教材更正、取捨說明 |

規格的順序即簡報頁序。整份規格先給老師看(摘要:錨點→頁對照、新增頁清單),再建頁。
