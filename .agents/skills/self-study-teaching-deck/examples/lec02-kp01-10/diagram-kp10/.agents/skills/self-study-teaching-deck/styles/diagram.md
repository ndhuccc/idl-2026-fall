# 風格一:圖解版

**一句話:** 圖就是解釋。版面乾淨,一頁一概念,把講義的數字與關係畫成圖,學生順著圖讀出結論。

## 版面參數(1280×720)

| 項目 | 規則 |
|---|---|
| 標題 | 左上,結論句,字級 32–36,粗體;右上小字「KPNN · 第 i/n 頁」 |
| 承接小標 | 標題下一行,字級 18–20,灰色,一句 |
| 主圖 | 佔版面 ≥ 60%,用全寬;吉祥物**不用**(可用小型印章/星形/勾叉等語意圖示) |
| 標註與文字框 | 字級 ≥ 18(公式 ≥ 24);每框一個意思,用完整短句 |
| 結論橫幅 | 底部深藍橫條,一句話,字級 24 |
| 揭示 | 2–3 拍:主圖 → 證據/算式 → 結論;重要頁可更多 |
| 導讀稿 | 每個揭示步驟都有;寫完整白話解釋,學生可只讀稿學會 |

## 設計要點

- 先問「這個概念最直觀的畫面是什麼」:曲線與座標、依比例的長條或面積、流程箭頭、並排對照。
- 圖用算出的數字畫(`*_nums.py`),標註數字與圖一致。
- 色彩角色固定(例如平方紅、絕對值藍、Huber 綠;目標紫、預測藍)。
- 不放大面積裝飾;趣味元素只承載意義(星形標最佳點、三角形標警示、菱形標判斷)。
