# 風格二:導學版

**一句話:** 吉祥物陪著讀。每頁有一個問題或提示的對話框、一行承接小標,圖解之外用步驟引導學生自己想,像有人陪讀。

## 版面參數(1280×720)

| 項目 | 規則 |
|---|---|
| 標題 | 左上,結論句,字級 32–36;下方一行承接小標(「承接 KPxx:…」或上一頁結論) |
| 主圖 | 佔左側約 3/4(x ≤ 1000),面積 ≥ 55% |
| 吉祥物 | **每頁都有**,固定角色(藍頭、紫身、橙觸角機器人),放右側 x 1025–1255;表情與道具隨概念換(困惑、得意、思考、量尺、放大鏡、天平、警示) |
| 對話框 | 吉祥物上方,一句短話(≤ 2 行),用「提問/提示」,不是複述標題 |
| 結論橫幅 | 底部淺綠橫條,一句話 |
| 揭示 | 3 拍:先問題與主圖 → 新證據與角色 → 結論 |
| 導讀稿 | 每個揭示步驟都有;帶學生做:先預測、再看結果、再解釋 |
| 練習與檢核 | 題目頁只給提示;解答放下一頁;題目頁的吉祥物做「請你想想」的姿勢 |

## 設計要點

- 一頁一個問題:上一頁的結論成為下一頁的問題。
- 比喻要畫出來(籃子、尺、橋、秤),並標明「比喻」,與講義實驗分開。
- 同一單元角色造型、配色固定;表情必須貼合概念。
- 文字框字級 ≥ 18;對話框 ≥ 20。

## 工具包

`examples/lec02-kp07/guided/建頁來源/`:`pagekit.py`(頁面與節點)、`mascot.py`(吉祥物與道具)、`specs.py`(頁面規格表)、`build_kp07.py`(建置)、`kp07_nums.py`(數值驗算)。
別的 agent 做其他 KP 時,複製這些工具後改 `specs.py` 與 `*_nums.py`。
