# 自學導向教學簡報(圖解版 / 導學版)

## 核心訴求

**簡報要能讓學生不靠老師講解,自己讀完就學會。** 老師上課時可能細講、略講或整份跳過讓學生自讀,所以:

- **頁數沒有上下限。** 頁數由講義內容決定;絕不為了「一個 KP 約 15 分鐘」或任何頁數目標而壓縮內容。
- 用「**覆蓋完整度**」取代頁數限制:講義的每個知識點、公式、算例、練習、易錯提醒、小測驗,都要在證據表對到至少一頁;每一頁也都要對到講義的某個段落。見 `tools/check_coverage.py`。
- 每頁自成一段完整的學習:學生看這一頁(圖 + 標註 + 結論 + 導讀稿)就能懂這一頁。

## 流程(每個 KP 依序做,不跳步)

1. **確認風格。** 老師一提出要做簡報:先說明(白話)兩種風格的差別,問用哪一種。
   - 圖解版:一頁一概念,圖就是解釋,版面乾淨,適合複習、公式與數據多的單元。
   - 導學版:吉祥物帶著走,每頁有對話框提問與小標銜接,像有人陪讀,適合第一次接觸的概念與自學。
   - 預設:導學版(自學導向)。老師可隨時改;同一門課建議同一風格。
   - 兩種風格共用同一份內容規劃(第 2–3 步),只是渲染不同。
2. **建立錨點清單並規劃頁面規格。** 執行 `python3 tools/check_coverage.py --list <講義.md>` 取得講義錨點(標題、粗體區塊標籤、編號練習、測驗列);依 `references/page-spec.md` 為每頁寫一列規格(來源錨點、承接、結論、新名詞、圖型、公式、數字、自我檢查)。一個錨點可拆成多頁,頁數不限。
3. **先寫提示詞、後設計。** 依規格寫「圖解提示詞」(逐頁:唯一結論、逐區內容、元件、數學排版、避免、檢查),再依它建頁。不要邊畫邊補。
4. **算數字。** 凡講義有算例、實驗或固定亂數種子結果,先寫 `*_nums.py` 重現並 `assert`;圖上的點、曲線、長條與標示的數字都由它產生。無法重現的標「概念示意」並說明原因。教材疑似有誤時列原值、重算值與依據,不靜默更改。
5. **建頁。** 依所選風格檔(`styles/diagram.md` 或 `styles/guided.md`)與共用規則(下節)用原生節點建 `lecNN-kpNN-*.jbd.json`,中英各一份。工具包見各風格檔。
6. **檢查。**(都要過)
   - `python3 tools/check_coverage.py <講義.md> <證據表.json>`:覆蓋完整度與自學欄位。
   - `python3 tools/check_style.py --style diagram|guided <簡報.jbd.json> <證據表.json>`:字級下限、吉祥物規則、必填欄位。
   - 預覽(`preview_deck.py`)溢位為 0;`check_deck_quality.py`、`scripts/check_slides.py` 無 FAIL。
   - 至少三輪「看圖 → 批評 → 修改」。批評要問:學生第一眼看到什麼?少了哪個自學需要的步驟?
7. **交付。** 簡報(中英)、圖解提示詞、圖解證據表、數值驗算、驗證說明;列出「錨點 → 頁」對照與未做的檢查。**不推送**,等老師看過並同意。

## 兩種風格共通的規則

- **每頁:** 一個核心結論(標題寫成結論句);一條視覺論證線;圖形佔版面最大區域(≥ 50%,圖解版 ≥ 60%);底部一句結論橫幅;小標「承接上頁」一行(第一頁寫承接哪個前置知識)。
- **文字:** 沒有字數上限,但**不堆整段**。頁面用圖、標註、算式與最短的解釋句;完整的白話解釋放進「自學導讀稿」(講者備註欄,學生下載時看得到,這是刻意公開的)。字級不低於 16。**不得為了版面而刪掉**定義、條件、限制、關鍵數值、算例的算式。放不下就拆頁。
- **新名詞:** 第一次出現的術語與符號,在該頁或之前的頁用白話解釋一次(保留正式詞,括號白話)。
- **算例要能核對:** 頁上出現的每個計算結果,其算式同頁可見。
- **自我檢查:** 講義有練習、小測驗、常見迷思時,各做成頁(題目頁 + 解答/解析頁);講義沒有時,每個主要概念後至少補一個「常見誤解」或「試試看」頁,標明為新增。
- **單元收尾:** 重點回顧頁 + 「下一個單元的問題」頁。
- **LaTeX:** 數學物件一律 `$...$`(KaTeX;不用 `\dfrac`、`\iff`、cases;`\text{}` 內不放中文);預覽不得殘留未渲染的 `$`。
- **逐步揭示(reveal):** 只用於同一個訊息的分拍呈現,每個揭示步驟都有導讀稿。
- **圖層:** 文字 `zIndex` 必須高於其下所有實心形狀。
- **顏色:** 全單元固定顏色角色;形狀與顏色雙重編碼。
- **原生元件與座標細節**(1280×720 頁面、1440 px 間距、連接線 hook、折線 ≤ 200 點、泡泡與想法泡泡尺寸):見工具包原始碼與 `page-to-teaching-diagram/references/jbd-native-elements.md`。

## 與 `page-to-teaching-diagram` 的差異

本技能保留其「來源忠實、數字可驗、LaTeX、原生元件、至少三輪修改」。**取消**其「每頁約 60 字、1–2 分鐘、單框 2 行」的課堂講授預算與頁數節奏,改以自學為標準(覆蓋完整度、新名詞、銜接、自我檢查)。

## 範例

`examples/lec02-kp07/`:同一個 KP(第 2 週 KP07 損失函數,講義約 17 KB、含練習與測驗)的兩種風格成品,與共用的頁面規格。先讀 `input/` 的輸入講義,再對照兩邊的成品與 `evidence-*.json`(看講義錨點怎麼對到頁);產出後拿自己的頁和對應風格的範例比。
