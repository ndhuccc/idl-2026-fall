# LAYOUTS.md — 版型庫(可擴充)

版型 = 一個函式 `build(spec, lang) -> NFig`,用 `@layout("名稱")` 登錄(`tools/figkit/layouts/`)。**版型是起點,不是限制**:找不到合適的,就擴充或用 `freeform`。

## 怎麼挑(依讀者在這一頁要做什麼,不依題材)

| 讀者要做的事 | 版型 | 結構 | 範例 |
|---|---|---|---|
| 並排比較 N 個情形,每個要看例子、代入、結果 | `columns_compare` | 圖例、N 欄(標題、圖示、代入式、大字結果、評語)、公式列、結論 | KP23 三個節點的不純度 |
| 一個起點、兩個選項,比較「正確做法」與「直覺做法」 | `two_options` | 起點、兩個選項(含分堆)、結果列(公式、判定標籤)、結論 | KP23 為什麼要加權 |
| 兩種狀態對比(小/大、有/無),各有示意、關鍵數字與差距 | `before_after` | 兩欄(示意、說明、兩個數字、差距)、資訊框、結論、備註 | KP23 樹要多大、KP12 參數計數 |
| 一個程序或因果鏈,N 步依序 | `steps_flow` | N 個方塊以箭頭連接(標題、算例、結果)、結論 | KP12 解題示範 |
| 影像、核、特徵圖、矩陣運算 | `grid_flow` | 格子與運算符號連成一或兩列、名詞小教室、結論 | KP12 權重共享的想法、等變與不變 |
| N 個選項在同幾個屬性上比較(做法、風險、條件) | `columns_text` | N 欄,每欄標題與標籤區塊、結論 | KP12 三條不變性路線 |
| 比較幾個數值(準確率、誤差、成本) | `bars_compare` | 橫條加數值、± 誤差線、備註、結論 | 20 份訓練集的準確率 |
| 一連串問題、條件或推導的分支 | `tree_diagram` | 節點方塊、帶標籤的邊、葉按結果上色、結論 | 決策樹分區 |
| 分層的網路或計算圖 | `network_layers` | 各層單元、連線(權重)、可標出一條路徑、每層的算式、結論 | 2-3-1 前饋網路 |
| 兩個是非問題產生四種情形 | `quadrant_2x2` | 兩軸標籤、四個彩色格(標題、說明、數字)、結論 | 混淆矩陣 |
| 學一個名詞或規則 | `concept_card` | 名詞、白話定義、例子/反例/為什麼等標籤區塊、公式列、結論 | 感受野 |
| 拆解一條公式,看每一項是什麼 | `equation_parts` | 公式各項各一個色塊、名稱與白話意思、代入數字、結論 | 不純度下降量的三個部分 |
| 小型 x-y 圖:曲線、折線、散點、參考線,右側可附說明卡 | `plot_xy` | 座標軸與刻度、折線(含標記與數值)、散點、水平/垂直參考線、側欄卡片、結論 | KP23 熵曲線、剪枝、高變異、斜向問題 |
| 以上都不合 | `freeform` | 用 `parts.py` 的零件自己組 `NFig` | KP23 分區圖、KP12 平移與旋轉 |
| 超過數百點的散點、需要平滑填色的曲面 | SVG(v1 `jbd_figure.py`) | 原生節點太多或畫不出來 | (目前沒有) |

目前共 **13 組版型**(上表前 13 列);`examples/layout_gallery.py` 有後六組(及 `plot_xy`)的範例 spec,`kp23_specs.py` 與 `kp12_specs.py` 示範前六組。PNG 輸出用 matplotlib 的數學排版,**不支援 `\tfrac`、`\dfrac`,請用 `\frac`**;簡報用 KaTeX 兩者皆可。

## 零件(`parts.py`)
`header_chip`、`panel`、`chip`、`outline_box`、`formula_bar`、`takeaway`、`legend`、`icon`/`icon_rows`(圓、方、三角代表三類)、`SKETCHES`(`tree_shallow`、`tree_deep`、`magnifier_note`)。色彩角色:`red blue green orange violet yellow teal grey`。新增零件直接寫在 `parts.py`,並在這裡加一行。

## 設計約束(所有版型共用)
1. 寬 1160、高 ≤ 480;標題與銜接條在圖外。
2. 字級 ≥ 16;亮底深字、淡底淺字(稽核 E10 檢查對比);純色,無陰影漸層。
3. 所有字串經 `T()`(`{"zh","en"}`);數字由 spec 帶入,spec 由程式算出。
4. 替代文字 `alt` 列出圖上每個數字與結論。
5. 版面常數(欄寬、列高)寫在版型函式裡,不要散落在 spec。

## 擴充版型(三步)
1. 複製 `tools/figkit/layouts/_template.py` 為 `<名稱>.py`,改幾何,用 `@layout("<名稱>", "一句話:服務什麼讀者任務")` 登錄。
2. 在這份表加一行(讀者任務、結構、範例)。
3. 在 `examples/` 放一個 spec 範例(用真實資料),渲染並看 PNG 與簡報截圖,通過稽核後再提交。
重複出現兩次以上的 `freeform` 圖,就該升級成版型。
