# 課程命題流程(本 Repo 專用)

> 適用:期中考、期末考、小考與題庫。**不適用**於作業截止後的「作業理解測驗」(見 `.agents/skills/assignment-quiz/SKILL.md`,
> 題目取自學生自己的程式、3 題簡答);兩者不要混用。

## 1. 先確認三件事(缺一就問老師,不要猜)

1. **考試範圍**:哪幾週、哪些講義(`lectures/`,以 `schedule.md` 的實際講義為準)。目前期中考、期末考範圍多為「考前另行公告」,未公告前不得自行決定範圍。
2. **題數、題型、Bloom 分布、配分、時間、語言**:未指定時提出技能預設(10 題、多選、25 分鐘、中英對照),並請老師確認。
3. **用途與匯入對象**:紙本、線上測驗,或要匯入 OnlineQuiz 題庫?匯入需另外取得老師對「具體站台與檔案」的同意。

## 2. 保密與輸出位置(紅線)

- **試題、答案、解析、品質報告、含正解的 JSON 一律不放進本 Repo**,連草稿也不放;不要 commit,也不要貼到 Issue、Discussions。
- 輸出寫到老師核准的**私人目錄**(Git 工作樹之外),並告訴老師實際路徑。
- 本 Repo 只可保存**不含答案**的資訊,例如考試範圍說明(`exams/scope-midterm.md`,對應週次與講義連結)。
- 考古題要公開前,先確認不會與本學期考題重複(AGENTS.md §5.8)。
- 不把成績、學號、名單寫進任何檔案。

## 3. 素材與來源

- 以 `lectures/` 內相應的講義為主要來源,逐題記錄來源定位(講義檔名、知識點 KP 編號、小節)。
- 教科書 Theodoridis & Koutroumbas, *Pattern Recognition*, 4th ed. 為對照;需要查核的專門事實以教科書或原論文確認。
- 講義與教科書衝突或疑似有誤時,列出衝突請老師裁定,不要默默採用其中一方。
- 無法讀取的來源如實說明,不假造內容。

## 4. 流程(沿用技能 Phase 0–3、5)

1. Phase 0 收集規格 → 2. Phase 1 命題藍圖(**等老師確認後**才逐題命題) → 3. Phase 2 逐題輸出 → 4. Phase 3 品質報告 → 5.(可選)Phase 5 JSON。
HTML(Phase 4)只在老師另有要求時才生成。

每題都要自行重新推導與驗算(含邊界條件、數值、單位);不可用「看起來正確」代替。

## 5. 命題規則(來自實際測驗系統的限制)

- 選項會被打亂:改為完整敘述,不用位置指涉;不用「以上皆是／以上皆非」。
- 單選恰有一個正解;多選的正解集合固定,不可有「多組答案都得滿分」的設計。
- 創造層需有實際建構證據,只有「評估既有方案」時保守標為評鑑。
- 難度、鑑別度寫「未經施測的專家預估」;沒有依據時寫「未估計」。猜對機率等說法不可當成實證。
- 技能的多選計分(分母為正確選項數)與 OnlineQuiz 的多選計分不同;匯入前明列實際計分規則,不宣稱匯入會改變線上計分。
- 全卷時間與單題時間不同:10 題共 25 分鐘,每題平均 150 秒僅為建議。

## 6. 公式

- 行內 `$...$`、區塊 `$$...$$`;**兩個 `$$` 區塊之間要空一行**(否則網頁出現多餘的 `$$$$`)。
- JSON 由序列化工具產生,反斜線要正確跳脫;公式要在實際 KaTeX／MathJax 環境目視確認,未檢查就標「未驗證」。

## 7. 交付物與驗收

分開交付:(1) 命題藍圖 (2) 教師版(答案與逐選項解析) (3) 學生版(只有題幹與選項) (4) 品質報告與來源對照 (5)(可選)OnlineQuiz 匯入 JSON(教師專用)。

OnlineQuiz 匯入 JSON 為完整物件,含 `name`、`description`、`default_points`、`default_timer_seconds`、`questions`;每題 `format` 為 `Single Choice` 或 `Multiple Choice`,2–10 個選項,`correct_answer` 為大寫字母串(如 `A`、`ACD`)。**本 Repo 沒有附匯入驗證腳本**;驗證與匯入需在 OnlineQuiz 專案或老師指定環境進行,未執行就標「原生驗證未執行」。

匯入前先向老師列出:站台 URL、題庫名與版本、題數與分布、配分與秒數、檔案與 SHA-256、影響範圍;等老師確認具體對象與內容後才匯入。沒有成功證據不得回報「已匯入」。

## 8. 完成後

- 在 `COURSE_STATE.md` 記錄:考試名稱、範圍、題數、產出保存位置(路徑,不含內容)、狀態。**不要記錄題目或答案。**
- 若老師要公告考試範圍,另寫 `exams/scope-*.md` 並依 §5.4 記錄 `CHANGELOG.md`。
