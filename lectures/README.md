# 講義(Lectures)

- 命名:該週正課用 `lec01.md`、`lec02.md`…(兩位數週次);同一週的補充或自主學習教材用 `lecNN-<代號>.md`,例如 `lec02-parameter-estimation.md`、`lec02-bayes-networks.md`。
- 每週可以有多份講義。`schedule.md` 該週的「講義」欄要列出全部,並在需要時註明哪幾份是必讀、哪幾份是自主學習。
- 格式:Markdown;行內公式 `$...$`,區塊公式 `$$...$$`
- 每份講義開頭須含:週次、對應實作、學習目標
- 圖片放於 `../assets/figures/`,以相對路徑引用;圖的代碼沿用該講義的代號(`lec02-` 或 `lec02-parameter-estimation-`)。
