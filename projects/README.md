# 期末專題(Final Project)

## 分組

- 每組建議 3–4 人(1–2 人亦可)
- 題目可從課程任一單元(必修或選修)選定;完全超出課程範圍的題目不建議
- 每位成員須有可追溯的 commit 貢獻(commit 訊息格式見 [課綱的生成式 AI 使用政策](../syllabus.md))

## 時程與繳交

| 項目 | 內容 |
|---|---|
| 期間 | 第 10 週起至第 17 週;確切截止日另行公告 |
| 配分 | 期末專題佔總成績 20% |
| 影片 | 8–12 分鐘,上傳 YouTube 並設為「不公開」;結構:動機 → 方法 → 結果/示範 → 結論 |
| 影片繳交 | 連結繳交到 e 學苑 |
| 報告 | 寫在 GitHub 專題 Repo(例如 `report.md`) |
| 第 17 週課堂 | 只有期末考,不做現場發表 |

## Repo 規則

1. 專題 Repo 與個人作業 Repo **分開**。個人作業 Repo 維持 Private。
2. 專題 Repo **繳交時才設為 Public**。截止後仍是 Private,視為未繳交,不接受補交例外。
3. 同學的影片與 Repo 於成績結算後供觀摩。

## 報告建議架構

1. 問題定義與動機
2. 相關工作
3. 方法(含數學符號,例如目標函數 $\min_\theta \; \mathcal{L}(\theta) + \lambda \lVert\theta\rVert_2^2$)
4. 實驗設計與結果
5. 討論與限制
6. 各成員貢獻
